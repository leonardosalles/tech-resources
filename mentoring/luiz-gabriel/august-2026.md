### 1. Learning Object Orientation
From August 3 to August 7.

What is a:
- ```class``` - blueprint for creating objects
- ```object``` - instance of a class
- ```attributes``` - properties that describe an object
- ```methods``` - behaviors/functions of an object
- ```constructor``` - initializes an object
- ```this``` - reference to the current object
- ```encapsulation``` - hiding internal implementation
- ```abstraction``` - exposing only what is necessary
- ```inheritance``` - reusing behavior from another class
- ```polymorphism``` - different implementations through the same interface
- ```composition``` - building objects using other objects
- ```access modifiers``` - public, private, protected

Then as action items:
- Create a ```Person``` class with attributes and methods
- Create a ```Car``` class with methods like ```start()```, ```stop()``` and ```accelerate()```
- Instantiate multiple objects from the same class
- Create a small project using at least 4 related classes (e.g. Library, Bank, School or Pet Shop)
- Use encapsulation by making some properties private and exposing getters/setters when appropriate
- Apply inheritance where it makes sense
- Use composition instead of inheritance when appropriate
- Explain why each class exists and its responsibility

August 7: ```Lightning Talk``` about Object-Oriented Programming, 5 minutes explaining the four pillars (Encapsulation, Abstraction, Inheritance and Polymorphism) with examples from your project.
